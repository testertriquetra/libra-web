GLITCH

This is an investigation report of a bug occurring on NTM Al-Kindi Model v.08

Some sort of markings were captured by the Machine. It is recognized to be some kind of glitch or a possible sabotage.

The glitch can be found appeared on the floor on the Lobby


Furthermore, based on the testimony from the tester, some data will revealed on the glitch location under a particular condition and setting of the machine.

For investigation purpose, these are the steps needed to make this data revealed:


1. Find the location of the glitch.

2. Using the machine, you need to go to CONFIGURATION

3. Reduce brightness to 0

3. Observe the data appeared on the screen


It's possible to find other instances of these glitches in many other places or objects. Further investigation will be conducted.
